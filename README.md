# AI-Based Fair Play Detection System for Esports

## Overview
An intelligent system that detects cheating in online games using 
machine learning, anomaly detection, and file integrity verification.

## Features
- Real-time gameplay behavior monitoring
- AI-powered anomaly and cheat detection
- File integrity verification using SHA-256
- Explainable AI for transparent decisions
- Admin dashboard for monitoring and reporting
